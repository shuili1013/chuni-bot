CHUNI Bot

把成績同步到 Discord，/rs 一指生成圖卡

▎ 推薦用法（搭配 Discord）

  1. 進邀請過 bot 的 Discord server，打 /bind 拿到專屬綁定連結。
  2. 打開連結，把按鈕拖到書籤列。
  3. 登入 CHUNITHM-NET，點書籤同步。
  4. 回 Discord 用 /rs 選歌，bot 直接吐圖卡。

▎ 不想用 Discord？仍可在本機產圖

把下面按鈕拖到書籤列，登入 CHUNITHM-NET 後點它，會在頁面 overlay 出最近 3 場合併圖卡：

🎵 CHUNI Plate (Local) ← 拖到書籤列（本機產圖，不需要綁定）

▎ 隱私 / 安全

  • 抓資料 100% 在你瀏覽器裡執行，cookie 不會送到第三方。
  • 同步到 bot 時只送解析後的成績資料（玩家名 / 分數 / 判定數），不送 cookie。
  • Bot 端只能用 sync token 寫入該 token 對應的帳號資料。
  • 用 /unbind 可隨時刪除你在 bot 端的所有資料。
